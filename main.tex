\chapter{USING THIS TEMPLATE}

This template satisfies the Grad Ed M.S. Thesis formatting requirements (the 2022-2023 guidelines, anyway, which are the most recent as of this writing in 2025). You should still consult with the thesis editing office on your draft as you are nearing graduation to ensure that added material conforms to current requirements. Before that final step, you will want to update the front matter, but should not need to modify the preamble (the section of the document above the \verb!\begin{document}! line) unless typesetting your thesis requires additional packages (\textit{e.g.}, algorithms, theorem environments, table customization, tikz graphics, etc.). For the most part, drafting within this template should be fairly plug-and-play: you just need to write up the thesis chapters and add them to the document with appropriate chapter headers. Chapter titles do not need to be capitalized, as is shown in this document, but you should use a consistent formatting style.

The material below provides some helpful information and tips on using LaTeX/BibTex/Overleaf. Note that it exemplifies the use of sectioning, which you may wish to use to structure your chapters. There are three sectioning depths: \verb!\section{...}!, \verb!\subsection{...}!, and \verb!\subsubsection{...}!. If you find yourself in need of more than three levels of subsectioning, you might want to rethink your use of headers. Sections should delineate the contents of each chapter. The document preamble specifies that only two depths appear in the table of contents, but all three are numbered. If you wish to have an unnumbered section, you can add an asterisk, \textit{e.g.}, \verb!\subsection*{}!; however, I would recommend avoiding unnumbered sections. If you need subheaders, you can change the document preamble so that the numbering depth stops at 2 and then use \verb!\subsubsection{}! for this purpose, but again, I would recommend against this. You can label sections for internal cross-references using a key like so: the next section is Section \ref{sect-math}. Don't cross-reference unnumbered sections.

\section{Math}\label{sect-math}

For inline equations, use a single \verb!$! as a delimeter for the math expression, \textit{e.g.}, $Y = X\beta + \epsilon$. To display an equation line, use the \verb!equation! environment. For a numbered equation line, use \verb!equation!:
\begin{equation}\label{eqn-lm}
    Y = X\beta + \epsilon
\end{equation}
For an \textit{unnumbered} equation line, use \verb!equation*!:
\begin{equation*}
    Y = X\beta + \epsilon
\end{equation*}
A general rule of thumb is to only number those lines that you cross-reference internally in the document. Note the addition of \verb!\label{...}! above; this allows for an internal cross reference to Equation \ref{eqn-lm}. In this document, equations are numbered consecutively by chapter (the cpthesis class sets this up automatically). This is adjustable if you so wish, but unless you have a \textbf{lot} of numbered equations, I wouldn't recommend numbering within sections, and unless you have \textbf{very few} numbered equations, I wouldn't recommend simple consecutive numbers.

To show a calculation spread over a few lines (or otherwise display a block of two or more equation lines), use the \verb!align*! environment:
\begin{align*}
    y_i &= \beta_0 + x_i^T\beta + \epsilon_i \\
    &= \beta_0 + \sum_{j = 1}^p x_{ij}\beta_j + \epsilon_i
\end{align*}
It's fairly unusual that you would want to number each line in a derivation, but it's possible by removing the asterisk; in that case, you can add labels for each line.
\begin{align}
    \label{eqn-lm1}
    y_i &= \beta_0 + x_i^T\beta + \epsilon_i  \\
    \label{eqn-lm2}
    &= \beta_0 + \sum_{j = 1}^p x_{ij}\beta_j + \epsilon_i
\end{align}
Then, we can refer to Equations \ref{eqn-lm1}-\ref{eqn-lm2} later in the document using the appropriate reference keys.

For further reference, \citet{latex-math} has a helpful guide to mathematical expressions. One small tip: use scalable delimiters in math expressions. It's a small detail, but makes a big difference in the overall appearance of your work. Compare the following:

\begin{equation*}
    \eta_i = g^{-1}(\sum_{j = 1}^p x_{ij}\beta_j)
    \quad\text{vs.}\quad
    \eta_i = g^{-1}\left(\sum_{j = 1}^p x_{ij}\beta_j\right)
\end{equation*}

\section{Figures and tables}

Notice that in this project, there is an \verb!img/! directory. You can upload image files there (or anywhere else in your project directory), and input them as figures in the document as follows:
\begin{figure}[!ht]
    \centering
    \includegraphics[width=0.5\linewidth]{img/normal-dist.png}
    \caption{The normal distribution.}
    \label{fig:normaldist}
\end{figure}
Figure captions should appear below the figure.

Tables are constructed directly in \LaTeX. For example:
\begin{table}[h!]
    \centering
    \caption{Some summary statistics.}
    \begin{tabular}{c|cc}
        Site & Size & Volume \\\hline
        019 & 1014.30 & 1305.08 \\
        030 & 918.19 & 1041.10 \\
        040 & 664.41 & 640.17
    \end{tabular}
    \label{tab:my_label}
\end{table}
Table captions should appear above the table. There are many nuances to table layouts and alignments. For more information, see \citet{latex-tables} or one of the various Overleaf guides on the subject. The \verb!xtable! package in R \citep{xtable} can be used to convert data frames and tables to latex tables; in conjuntion with \verb!clipr!, this can really streamline table generation.

\section{Citations}

The file \verb!refs.bib! contains some example references in BibTex format. I tried to capture the most commonly used entry types: articles, books, book chapters, R packages, and web resources. For academic literature, Google scholar will generate these entries for you, although you should review for consistent formatting (capitalization of journal titles, missing authors, extraneous information, etc.) before inputting into your \verb!.bib! file. Each entry has a key that you can use to cite the entry; by default, only cited entries will appear in the bibliography generated at the end. If you wish to customize the appearance of the bibliography, you can select from among several styles and fine-tune options to suit your preferences. See \citet{bibtex} or Overleaf guides for further information.

Textual citations use the \verb!\citet! command and are useful for referring explicitly to a reference in a sentence. For example: \citet{bibtex} provides a helpful guide to reference management using BibTeX.

Parenthetical citations use the \verb!\citep! command and are more often used in academic writing. For example: stability selection is a general method of variable selection that provides theoretical guarantees on the expected number of false discoveries under mild assumptions \citep{meinshausen2010stability}. A list of citations can be provided by separating the bibtex keys by commas. For example: envelope methods improve estimation efficiency in statistical models by leveraging low-dimensional structure in multivariate data salient to a relationship of interest \citep{cook2010envelope, cook2013envelopes, cook2015foundations}.

The two citation types have a uniform appearance across reference entries that is controlled by the options specified for the \verb!natbib! package. For a quick guide to customizing citation appearances, see the document by \citet{natbib-guide} (check the URL in the bibliography entry).
